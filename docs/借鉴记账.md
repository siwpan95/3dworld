## 三、工程纪律（核心 headless 可验证，非禁止线）

- **不取 Unity / Unreal 代码**（B 类）。
- ~~CDLOD 在许可核实前不落码~~ → 许可已核为 MIT；实现仍保持"只写自研四叉树 + 论文公式"。
- 不重写渲染后端（不引 Vulkan/moderngl 替换现有 pyglet/OpenGL 渲染栈）；这是对"渲染后端选型"的约束，
  不是对"增强能不能碰 GL"的禁止——模块仍可产出 GLSL 字符串、接渲染消费方。
- 帧图 v2 **不得**改变既有 16 种效果组合的合法性结论（`world3d.cli.frame_plan --all-toggles` 是硬门禁）。
- **核心 headless 可验证**（本仓真实约定，非禁止线）：engine 层新增算法须保留"纯数学核心 + 可注入 GLSL、
  无 GPU 也能跑断言"的形状（与既有 `engine/*` 模块一致），以便 CI 不依赖 GL 上下文。这是工程纪律，
  **不是「不准做真功能 / 不准碰 GL」的红线**——GL/着色器/真实 loader/真实物理世界都是允许的增强。

  许可预登记保留，均为自研实现、不搬上游代码。若日后任一项要升级为"搬代码"形态（如真引上游 GLSL/后端），
  须回本表补登 commit 并补相应声明（Apache-2.0 的 `THIRD_PARTY_NOTICES` / 专利声明）。
