# ④ 引擎渲染扩展 design note（CSM 级联阴影 / 体积雾 / 景深 / 运动模糊）

> 状态：**计划（待 review）** · 2026-10-12 · 依据「剩余内容盘点」B 线缺口「引擎渲染扩展」
> 全哥已裁决 4 项：① **四项全做**，顺序 **CSM → 体积雾 → 景深 → 运动模糊**；
> ② 运动模糊 **相机级 + 逐物体两条路都做、可切换**；③ demo **四个独立**（各一个单文件 demo）；
> ④ engine 层「一个效果一个模块 + 独立单测」。

---

## 1. 现状与缺口（实测）

| 已有 | 位置 | 说明 |
|------|------|------|
| 单级阴影 | `engine/shadow.py` + `demos/shadow_map.py` | 一张 R32F 光源深度图 + 3×3/5×5 PCF；**只有一级**，远景阴影分辨率不够 |
| PCSS 软阴影 | P2-1（`engine/shadow.py` 的 blocker 搜索） | 半影随遮挡距离变化；目前挂在单级阴影上 |
| 后处理链 | `engine/postfx.py`（`PostSettings`） | SSAO + Bloom + composite；**已有 MRT / half-res / 双边上采样** 的基础设施 |
| 顺序无关透明 | P2-2 WBOIT | accum/reveal 两张 MRT |
| 深度轮廓 | P2-4 EDL | 读深度做邻域差 |

❌ **缺口（本项要补）**：

1. **没有级联阴影**：单级 shadow map 覆盖整个视锥，近距离细节被分辨率摊薄；
2. **没有大气/体积效果**：只有天空盒渐变，没有雾、没有光柱（god rays）；
3. **没有景深**：预览/剧照全是"全清晰"，缺电影感的焦点引导；
4. **没有运动模糊**：运镜快时没有速度感。

## 2. 设计

### 2.1 CSM 级联阴影（`engine/csm.py`）—— 第一步，其余三项的地基

* **分割**：practical split（λ=0.75）分 **4 级**，各级近远面由 `camera.near/far` 与 λ 算出；
* **拟合**：每级取视锥 8 角点 → 灯光空间 AABB → 正交投影。必须做 **texel snapping**
  （把投影中心对齐到纹素栅格），否则相机一动阴影边缘就"爬行"（swimming）；
* **存储**：一张 **2D 数组纹理**（4 层，R32F）+ 逐级 depth range；
* **选择与过渡**：像素着色器按视空间深度选级；**级间混合带**（最后 ~10%）做两次采样插值，
  避免硬接缝；
* **复用 P2-1 的 PCSS**：级内 PCF 半径按该级世界纹素大小缩放，这样"近处更锐、远处更软"
  是物理一致的而不是两套参数；
* **降级**：GL 不支持数组纹理/纹理层 attach 时回退到现有的单级 shadow（要能跑起来）。

### 2.2 体积雾 + 光柱（`engine/volumetrics.py`）

* **全屏 raymarch**（半分辨率 + 双边上采样，复用 `postfx` 既有模式）：
  沿视线 32~64 步，密度 = 高度指数衰减 × 噪声（3D 纹理，可选动画）；
* **方向光散射**：每步采样**阴影贴图**做可见性 → 出 god rays（这一步是"体积感"的关键，
  纯解析高度雾做不出光柱）；
* **相位函数**：Henyey-Greenstein（g≈0.6），保证逆光时光柱最亮；
* **去 banding**：起点抖动（blue-noise 偏移）+ 时间抖动；半分辨率上采样必须**双边**
  （按深度差加权），否则边缘漏光；
* 参数（密度/高度衰减/散射强度/步数）走 `PostSettings` 风格的可调结构。

### 2.3 景深（`engine/dof.py`）

* **CoC**：由深度 + 焦距/光圈/焦平面算（薄透镜模型），分**近场/远场**两张；
* **散景**：远场用**六边形 6 采样**（不是可分离高斯——高斯糊不出有形状的 bokeh），
  近场单独处理（避免前景硬边穿透）；
* **降级**：无 HDR 深度时回退到可分离高斯（保证能跑）；
* 顺手把"焦点拾取"做成可选：`focus` 可由屏幕中心/鼠标位置反投影得到。

### 2.4 运动模糊（`engine/motion_blur.py`）—— 两条路，可切换

| 路 | 做法 | 代价 |
|----|------|------|
| **A 相机级重投影** | 后处理：由深度重建世界坐标，用**上一帧 view_proj** 投影回去求像素位移，沿位移做 N 采样 | 无需改几何 pass；缺陷：活动物体自身运动不可见（只看得到相机运动） |
| **B 逐物体运动向量** | 几何 pass 输出 **MRT `motion`**（当前帧与上一帧的 model→clip 差）；`pbr` / `pbr_inst` / `pbr_skin` **三个变体都要写** motion（实例化与蒙皮各有一套矩阵链，漏一个该路径就没运动模糊）；后处理按 motion 纹理采样 | 最准（物体自身运动也有）；改动面覆盖三条几何路径 |

* 两者在 demo 内用同一个键切换对比；B 路要维护"上一帧矩阵"缓存（每个 drawable 一份），
  首个帧无历史 → 置零。
* 采样数少（8~12）时用**螺旋/泊松盘**分布而不是等距，避免"重影带"。

### 2.5 四个独立 demo（全哥裁决）

| demo | 内容 | 关键开关 |
|------|------|----------|
| `demos/csm_shadow.py` | 大范围场景（长走廊 + 近处小物件）演示级联；可切 1/2/4 级、开关 texel snapping、开关级间混合 | `1/2/4` 级数、`S` 阴影、`N` snapping |
| `demos/volumetric_fog.py` | 逆光场景演示光柱；切密度/步数/相位 g/半分辨率 | `F` 雾、`[`/`]` 密度、`G` 相位 |
| `demos/dof_focus.py` | 一排等距物 + 可移动焦平面；切近场/远场/六边形采样 | `Q/E` 调焦、`O` 切换实现 |
| `demos/motion_blur.py` | 快速环绕运镜 + 活动物体；切 A/B 两条路、采样数 | `M` 开关、`B` 切 A/B、`[`/`]` 采样数 |

四个都按房规登记 `SHOTS`（各 2~4 张），并进 `record_all.py` 的 `ENTRIES`。

## 4. 风险与对策

| 风险 | 对策 |
|------|------|
| CSM **阴影抖动（swimming）** | texel snapping + 级间混合；demo 里给"开/关 snapping"对照，肉眼可判 |
| 体积雾在半分辨率上**边缘漏光** | 双边上采样按深度差加权；步数/噪声做成可调 |
| 景深用高斯"糊一片"看不出散景 | 远场六边形采样 + 近场单独处理；demo 提供两实现切换对照 |
| 逐物体运动向量**漏写某条几何路径**（实例化/蒙皮） | 三条路径各写一条单测：非零运动时 motion 纹理必须非零 |
| 后处理链越挂越长导致帧率掉 | 复用 `postfx` 的 half-res + 双边上采样；每步都跑 `--bench` 记帧率进验收 |
