## 调研范围

- **完整引擎**：Godot 4.x（本地 clone 实测 14,434 文件）、Unreal Engine 5、O3DE、Flax、MonoGame、Stride、Lumix、Irrlicht、Cocos2d-x、rbfx
- **渲染**：RHI 抽象、帧图（UE RDG / Godot RDG / Filament）、Clustered Forward、Nanite/Lumen、Bindless/光追、FSR2
- **物理**：Box2D v3、Jolt、Rapier、Bullet（宽相/窄相/求解器/确定性）
- **ECS**：EnTT、flecs、Bevy（四种存储范式）
- **底层库**：bgfx、SDL3、GLFW、raylib
- **经典引擎**：Quake、Doom、ioquake3、OpenMW、Cataclysm DDA

## 证据分级约定

- **A 级** = 本地 clone 源码实测；**B 级** = GitHub REST API 实时抓取；**C 级** = 官方文档 / SIGGRAPH 论文；**D 级** = 社区二手
- 未验证项与全部修正痕迹见主报告附录 B（含 5 处"博客级证据被当源码级证据"的勘误记录）

## 与本仓库（3dworld）的关系

本调研是 `world3d` 引擎化改造的**外部参考材料**：帧图（P3-a/P3-b design note）、GPU 驱动渲染（P3-1）、蒙皮骨骼（P2-3）、渲染扩展（④）等方向的既有设计，可与报告中 Godot RDG / UE RDG / bgfx 枚举边界 / Box2D-Jolt 确定性对照阅读。第三方引擎各有其自身许可，本目录仅收录调研文本，不含任何第三方源码。
