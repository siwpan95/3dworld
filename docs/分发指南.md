# 分发指南（引擎库）

> 2026-10-19 demo 剥离后重建：本仓是**引擎库**，分发渠道是 PyPI；
> 演示程序 / 成片 / exe / Gitee release 的分发已随 demo 迁往独立仓
> `siwpan/3dworld-demos`（其 `docs/分发指南.md` 保留录制/打包/发行版的完整手册）。

## 一、PyPI 发布（现行渠道）

发行名 `3dworld` / 导入名 `world3d`；版本双轨：库用 SemVer（`pyproject.toml` 的
`version`），发行版（Gitee release / exe / 成片）继续 CalVer（`VERSION` 文件）。

### 标准流程（2026-10-15 首发 0.1.0 实测走通）

```bat
:: ① 构建（隔离环境，build + twine）
<PATH>\Scripts\python.exe -m build

:: ② 校验（双 PASSED 才能传）
...python.exe -m twine check dist/3dworld-<版本>.tar.gz dist/3dworld-<版本>-py3-none-any.whl

:: ③ 干净 venv 冒烟（装 wheel → world3d-info 全绿 → 三个入口可达）
...python.exe -m venv <临时目录>\3dworld-smoke
<临时目录>\3dworld-smoke\Scripts\pip.exe install <wheel 路径>
<临时目录>\3dworld-smoke\Scripts\world3d-info.exe

:: ④ TestPyPI 沙盒（令牌在 <凭据目录>\私人令牌.txt 第 13 行，指向 test.pypi.org）
set TWINE_USERNAME=__token__
set TWINE_PASSWORD=<TestPyPI 令牌>
...python.exe -m twine upload --repository testpypi dist/3dworld-<版本>*

:: ⑤ 正式上传（第 15 行令牌，指向 pypi.org）—— **高风险，须全哥放行**
...python.exe -m twine upload --repository pypi dist/3dworld-<版本>*

:: ⑥ 核对：页面 200 + 元数据（PyPI JSON API）
curl -s https://pypi.org/pypi/3dworld/json
```

### 凭据口径（2026-10-15 核实）

- `<凭据目录>\私人令牌.txt`：第 13 行 = TestPyPI 令牌，第 15 行 = PyPI 令牌；
  （`<凭据目录>` 与 `<PATH>` 同为占位符 —— 铁律 5 不烤盘符，按本机实际位置替换）
  令牌内嵌 base64 服务器标识（`test.pypi.org` / `pypi.org`），用前可解码头缀核对归属；
- 令牌只经环境变量传给 twine，不回显、不入库；
- 上传属高风险外部动作：先 TestPyPI 沙盒验证，正式上传前逐项确认。

### 打包范围（wheel 内容口径）

- wheel 只含 `world3d`（含 py.typed）+ vendored `cordis`；
- `tests/` / `scripts/` / `docs/` / `assets/` / `recordings/` / `configs/`
  不随 wheel 分发（`examples/` 已迁出）；
- `configs/` 是仓库资产：`world3d-config` / `world3d-pipeline` 从仓库运行天然可用，
  非 editable 安装用环境变量 `WORLD3D_CONFIGS` 指向配置树目录。

## 三、记账（来源与许可）

- **PyInstaller**：GPL-2.0 with bootloader exception（打包产物无传染约束）；
  来源 PyPI。仅作打包工具，不修改其代码。（使用方：3dworld-demos 仓）
- **ffmpeg**（本地转码用）：gyan.dev essentials/full build（GPL）；
  仅本地使用，不随产物分发其二进制。（使用方：3dworld-demos 仓）
- **twine / build**：Apache-2.0；来源 PyPI。仅作发布工具。
